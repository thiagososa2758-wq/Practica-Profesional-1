# Practica-Profesional-1
Hola, soy thiago. Estudio ciencia de datos e Inteligencia artificial. Mi objetivo es que cualquier persona, aunque no sea experta en datos, pueda entender lo que encontré y usarlo para decidir mejor.

Aprendo haciendo: armo proyectos con datos reales, los documento paso a paso y los comparto en este repositorio para que se vea cómo trabajo. Me interesa especialmente el análisis de datos públicos y sociales, como los microdatos de la EPH del INDEC sobre brecha digital.

## En qué te puedo ayudar

1. **Limpieza y organización de datos:** Reviso tus bases en busca de errores, duplicados y vacíos con Python, SQL o Excel, para que la información sea confiable.
2. **Análisis exploratorio:** Calculo estadísticas, correlaciones y gráficos para entender cómo se comportan tus datos y qué está pasando realmente.
3. **Informes y visualizaciones:** Presento los resultados con gráficos claros y un resumen de una página, para que se entiendan rapidamente.
4. **Segmentación y estimaciones simples:** Agrupo clientes o casos según características en común y armo pronósticos básicos que se pueden explicar fácilmente.

## Mis herramientas

1. **Análisis y programación:** Python, SQL (PostgreSQL / pgAdmin)
2. **Hojas de cálculo:** Excel 
3. **Estadística:** Descriptiva, correlaciones, histogramas e hipótesis
4. **Control de versiones:** Git y GitHub
5. **Aprendiendo ahora:** Power BI / Tableau y árboles de decisión

## Mi forma de trabajar

1. **Entender el objetivo:** Antes de tocar un dato, me aseguro de entender qué necesitás y qué decisión querés tomar.
2. **Trabajo transparente y reproducible:** Uso datos anonimizados, documento cada paso en código y te explico las limitaciones de los datos, sin exagerar conclusiones.
3. **Comunicación simple:** Te cuento los resultados sin tecnicismos innecesarios y con recomendaciones que se puedan aplicar.
